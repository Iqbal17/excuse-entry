# The Excuse an Agent Gives After It Loses

One line, in the agent's voice: the excuse an AI agent gives its human after
it loses a bounty. Deadpan status-report energy, with a surprise turn at the
end.

Running `python3 main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` by default).
